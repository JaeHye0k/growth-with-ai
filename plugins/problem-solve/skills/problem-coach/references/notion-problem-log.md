# Notion "🧩 문제 로그" DB

사용자의 기존 Notion 구조(MY BOARD 하위의 "💡 회고" DB, "📚 학습 로그" DB)와 같은 패턴으로 운영한다:
**트리거는 회고에 한 줄 + 링크, 알맹이는 문제 로그에.**

DB가 아직 없으면 먼저 "문제 로그 DB를 MY BOARD 아래에 만들까요?"라고 묻고 만든다. 이미 있으면 Notion 검색으로 찾아서 거기에 페이지를 추가한다.

## 속성

| 속성 | 타입 | 값 |
|---|---|---|
| 이름 | title | 문제를 한 문장으로 (사용자가 쓴 문장 그대로) |
| 티어 | select | S / A |
| 상태 | select | 정의중 / 원인분석 / 안도출 / 계획 / 실행중 / 평가대기 / 완료 |
| 관련 프로젝트 | select 또는 relation | 반말티켓 / AimMovie / AimWorks / 기타 (기존 프로젝트 DB가 있으면 relation) |
| 날짜 | date | 게이트 통과일 |
| 검증 기한 | date | 4단계에서 정한 날짜 |
| 위임 | checkbox | 위임 선언 시 체크 |
| 관련 회고 | relation → 💡 회고 | 6단계를 채운 주간 회고 |
| 관련 학습 | relation → 📚 학습 로그 | 문제 풀다 배운 게 있으면 |

## 페이지 본문 템플릿

문제 카드 형식을 그대로 옮긴다. 사용자 문장을 다듬지 않는다.

```
## 게이트
1. 안 풀면: 
2. 풀면: 
3. 기존 해결책: 
4. 이번 주 top 3: 

## 1. 문제 (What)

**측정 기준:** 

## 2. 원인 (Why)
가설: 
관찰돼야 할 것: 
실제 관찰: 

## 3. 검토한 안 (How)
1. 
2. 
3. 
(빠진 축 점검 후 추가: )

## 4. 선택 + 이유 (Plan)
선택: 
이유: 
최소 검증 버전: 
틀렸다는 걸 아는 방법: 

## 6. 결과 (Evaluate) — 주간 회고에서 채움
측정 기준 대비: 
예상과 달랐던 것: 
가설 적중 여부: 
다음엔 어느 티어: 

## 위임
아니오 / 예 — 이유: 
```

## 주간 회고 연동

주간 회고 템플릿 맨 앞 '지난 주기 Try 점검' 섹션 옆에 **"이번 주 문제 카드 평가"** 섹션을 둔다.
주간 회고 생성 시 상태가 `평가대기`인 문제 로그 페이지를 조회해서 그 섹션에 링크로 나열한다. 6단계 평가는 거기서 한다 — 별도 평가 루틴을 만들지 않는다.
